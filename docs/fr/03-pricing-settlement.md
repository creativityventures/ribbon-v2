# Pricing, options et settlement

Le pricer détermine la prime et les contrôles de prix utilisent les paramètres de marché. Le settlement détermine ensuite la valeur due selon le type d’option, le strike, le prix de règlement et la quantité.

Les bibliothèques `ShareMath` et les contrats de test visibles dans le dépôt sont utiles pour repérer les arrondis et les bornes. Elles ne sont pas exécutées dans ce parcours.
