# Ribbon V2 : vaults de rendement

Ribbon V2 organise des vaults qui vendent des options couvertes pour générer un rendement. Un vault détient un actif, ouvre une série d’options et distribue la valeur aux parts selon un cycle de dépôt, de vente et de règlement.

Le code sépare le coffre, le pricer, l’oracle de volatilité, le sélecteur de strike et les tokens d’option. Cette composition permet d’isoler les décisions de stratégie.
